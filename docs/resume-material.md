# 可核验简历素材

**项目简介**：Mini-dsh 是面向代码任务的 Python Coding Agent Harness，提供多轮执行、可替换 Context 策略、统一工具运行时、执行 Trace、保守会话恢复和独立评测。

**技术栈**：Python 3.11、typing.Protocol、依赖注入、Agent Loop、Context Engineering、Docker、MCP、JSONL Trace、uv、pytest。

**核心贡献**：

1. 实现支持步数、Token、工具调用与墙钟预算的多轮 Agent Loop，使用 Protocol 注入模型、Context、工具、权限、会话和可选事件接收器；实现插件依赖排序、启动失败回滚与逆序清理。
2. 实现六种可替换 Context 策略，分离追加式 Session Event 与每次请求的实际 Context View，记录选择范围、内容哈希和索引刷新原因；通过六策略实验框架保存输入和配置快照。
3. 统一文件、命令、Docker 和 MCP 工具的参数校验、权限、超时与结构化结果；加入文件路径和符号链接检查、进程组清理、单次输出捕获及 Session 产物配额，并在恢复时拒绝结果不确定的副作用调用。
4. 建立公开与留出测试、JSONL Trace、实验完整性校验、费用离线重算和 Trace 差分；可区分首次上下文差异与首次可观察行为差异。增加独立 SHA-256 锚点和可搬运实验归档，在本地验证搬运后复核及篡改检测。

**可核验结果**：固定基础镜像摘要后的六任务 × 六策略脚本模型评测 36/36 次通过公开及留出测试，36 条 Trace、独立锚点和可搬运归档通过校验；这只验证评测链路。正式真实模型批次覆盖六任务 × 六策略 × 三次，共 108 次 DeepSeek Flash 运行，70/108 次通过公开及模型不可见的留出测试；108 条 Trace、输入快照、137 个锚定文件和 176 文件 ZIP 均通过校验。按任务配对的 `summary` 相对 `full_history` 总 Token 中位差 +463.1%、价格快照估算费用中位差 +355.8%、缓存命中率中位差 −31.7 个百分点；这些是本任务集的观察值，35 次预算耗尽与执行步数差异会影响比较，不应写成一般策略优劣或成本优化。已用同任务同策略 Trace 差分定位两个失败案例：模型提前结束、错误补丁路径后未完成跨文件修复；见 [案例记录](trace-cases-20261015.md)。较早 36 次真实运行中的 11 次 HTTP 503 应与正式批次分开报告。历史所称“1,010 次”等数字及未经验证的成本优化比例不写入简历。

**可直接用于简历的一段**：实现六种可替换 Context 策略及 Event/View 分离，建立包含任务输入快照、独立锚点、留出测试和 Trace 差分的评测链路；在六任务 × 六策略 × 三次的 108 次 DeepSeek Flash 真实运行中，70 次通过公开及留出测试，108 条 Trace 均通过完整性校验。通过同任务同策略 Trace 对比定位模型提前结束与错误补丁路径后的恢复失败；同时发现不同策略的执行步数和预算耗尽率明显影响 Token、缓存与费用对比，因此将费用明确标为价格快照估算。
